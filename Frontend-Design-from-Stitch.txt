      canvas.width = rect.width * window.devicePixelRatio;
      canvas.height = rect.height * window.devicePixelRatio;
      ctx.scale(window.devicePixelRatio, window.devicePixelRatio);
      ctx.lineWidth = 2.5;
      ctx.lineCap = 'round';
      ctx.strokeStyle = '#b4c5ff'; // Primary theme color
    }
    resizeCanvas();
    window.addEventListener('resize', resizeCanvas);

    function getCoords(e) {
      const rect = canvas.getBoundingClientRect();
      const clientX = e.touches ? e.touches[0].clientX : e.clientX;
      const clientY = e.touches ? e.touches[0].clientY : e.clientY;
      return {
        x: clientX - rect.left,
        y: clientY - rect.top
      };
    }

    function startDraw(e) {
      isDrawing = true;
      placeholder.style.display = 'none';
      const pos = getCoords(e);
      ctx.beginPath();
      ctx.moveTo(pos.x, pos.y);
      e.preventDefault();
    }

    function draw(e) {
      if (!isDrawing) return;
      const pos = getCoords(e);
      ctx.lineTo(pos.x, pos.y);
      ctx.stroke();
      e.preventDefault();
    }

    function stopDraw() {
      isDrawing = false;
    }

    canvas.addEventListener('mousedown', startDraw);
    canvas.addEventListener('mousemove', draw);
    window.addEventListener('mouseup', stopDraw);

    canvas.addEventListener('touchstart', startDraw, { passive: false });
    canvas.addEventListener('touchmove', draw, { passive: false });
    window.addEventListener('touchend', stopDraw);

## Brand & Style

This design system establishes a high-density, mission-critical operations environment tailored for freight brokerages, logistics dispatchers, risk officers, and carrier compliance analysts. Rooted in the analytical precision of mission-control platforms like Palantir, Highway.com, Truckstop RMIS, and Linear, it rejects consumer-style decorative whitespace in favor of maximum informational throughput, strict visual triage, and deterministic risk verification.

### Personality & Demeanor
- **Surgical & Deterministic:** Every pixel serves operational clarity. Carrier vetting outcomes require zero subjective interpretation: data points exist in unequivocal states of compliance, risk review, hard breach, or missing evidence.
- **Vigilant & Unyielding:** Engineered for rapid fraud mitigation, chameleon carrier detection, and identity spoofing prevention under time-sensitive dispatch pressure.
- **Technical & Trustworthy:** Built with industrial polish—crisp dark-slate surfaces, hairline grid borders, specular top highlights, and tabular monospace figures that reflect institutional grade rigor.

### Visual Style
- **Control Room Dark UI:** Deep obsidian-navy canvas surfaces minimize eye fatigue over 12-hour shifts while allowing luminous signal markers (Emerald, Amber, Crimson) to instantly flag anomalies.
- **Machined Layering:** Subtly elevated panels, micro-etched cybernetic borders, 1px specular white top-edge highlights (3% opacity), and translucent card backdrops produce a physical, structural presence without clutter.
- **Information-Dense Minimalism:** Tight padding, systematic vertical rhythms, and right-aligned numeric data allow brokers to monitor 30+ carrier dossiers, active loads, and safety thresholds concurrently.

## Colors

The color palette prioritizes legibility, high dynamic contrast, and strict four-state operational safety protocols. Colors are not decorative; they are functional signaling mechanisms.

### Structural Foundations & Surfaces
- **Canvas (`#05080f`):** The master viewport root canvas. Pure dark graphite-navy void.
- **Surface Shell (`#0a1020`):** Base container fill for sidebars, persistent headers, inspectors, and elevated workspace panels.
- **Surface Card & Header (`#0e1628`):** Elevated cards, table header strips, input containers, and floating controls.
- **Surface Hover & Highlight (`#131d33`):** Interactive row hovers, ghost selections, and skeleton loading pulses.
- **Hairline Border (`#1b2740`):** Default 1px dividing grid lines separating cards, cells, and drawer sections.
- **Interactive Border (`#25334f`):** Form input outlines, custom scrollbars, and unfocused active interactive boundaries.
- **Elevated Border (`#35466a`):** Active scrollbar indicators, hover-state card borders, and primary dividers.

### Text & Metrics Ramp (Cool Mist)
- **Display White (`#f4f7fc`):** Primary metric figures, view headers, modal titles, and active entity names.
- **Primary Body (`#e6edf8`):** General UI text, active values, and table values.
- **Secondary Body (`#c4d2e6`):** Carrier legal names, equipment specs, and origin-destination routes.
- **Muted Data (`#9fb1cc`):** Policy underwriters, timestamps, cell secondary text, and inactive toggles.
- **Subtle Guidance (`#7d90af`):** Explanatory helper text, disabled values, and navigation icons.
- **Micro-Tracker (`#64769a`):** Uppercase column heads, data keys, and table metadata indicators.

### Accent & Action
- **Signal Azure (`#2563eb` interactive, `#3b82f6` hover, `#6ba4ff` focus glow):** Primary CTAs, dispatch confirmations, active tab highlights, and verified links.

### Deterministic Vetting & Fraud States
Every carrier vetting check, chameleon risk score, and safety audit computes into one of four immutable states:
- **PASS (Verified / Cleared):** `#22c55e` (dot/accent), `#4ade80` (text/icon), `#052e16` (background). Signifies verified FMCSA authority, active verified COI, satisfactory safety scores, and verified physical addresses.
- **NEEDS_REVIEW (Warning / Chameleon Flag):** `#f59e0b` (dot/accent), `#fbbf24` (text/icon), `#2a1a03` (background). Signifies reincarnated carrier ties, expiring certificates, unverified phone/email, or safety inspection spikes.
- **FAIL (Breach / Fraud / Blacklist):** `#ef4444` (dot/accent), `#fb7185` (text/icon), `#2c0809` (background). Signifies revoked authority, lapsed auto liability, high double-brokering risk, or active freight fraud reports.
- **UNKNOWN (Insufficient Evidence):** `#64748b` (dot/accent), `#94a3b8` (text/icon), `#1e293b` (background). Signifies unindexed authority or unverified RMIS sync. Missing evidence strictly never counts as a pass.

## Typography

Typography prioritizes rapid horizontal reading across tables and immediate vertical scanning of metrics. Font pairs are split strictly by purpose:

- **Primary Interface Font (Geist):** Clean, geometric, neutral grotesque tailored for dense data interfaces, high information packaging, and low-fatigue scanning.
- **Audit & Identifier Font (JetBrains Mono):** Dedicated to mission-critical logistics keys: USDOT identifiers, MC/FF dockets, VIN hashes, cargo coverage values ($100,000+), insurance policy numbers, reason codes (`REINCARNATION_PROXIMITY_FLAG`), and ISO-8601 UTC timestamps.

### Rules of Usage
1. **Numbers & Tabular Alignment:** All financial amounts, deficit metrics, inspection percentages, and dates must use tabular numeric lining (`tabular-nums`) to preserve column alignment.
2. **Metadata Headers:** Table header titles and dossier metadata keys must always use `label-micro`, rendered in uppercase with wide tracking (`0.1em`) and subtle mist tint (`#64769a`).
3. **Data Identifiers:** Carrier registration numbers and load IDs are treated as actionable links, styled in `data-mono` with primary brand coloring (`#6ba4ff`) on hover.

## Layout & Spacing

The layout is built as an unyielding, fixed-shell operations console. The master container occupies 100% of the viewport height with zero global window scroll; internal viewports, tables, and sidebars utilize isolated scrolling panes.

### Shell Architecture
- **Control Bar (Header):** Fixed height of 52px, anchored at the top, bordered below with hairline `#1b2740` and backdropped with `#0a1020` at 80% opacity plus background blur. Houses search, carrier quick-lookup, live system sync indicators, and auth profiles.
- **Operations Rail (Sidebar):** Fixed 256px column (non-collapsing on desktop), housing high-priority workflow links (Carrier Directory, Live Load Board, Fraud Watchlist, Certificate Audit, Dispatch Clearance).
- **Master Stage:** Fluid canvas spanning the remaining viewport width, with uniform `1.5rem` outer margins.

### Grid & Density Rhythms
- **4px Base Rhythm:** All vertical distances follow strict multiples of 4px. Metric badges, button heights, table rows, and alert callouts anchor directly to this rhythm.
- **KPI Metric Strip:** Responsive 4-column layout (`grid-cols-4` on desktop, `grid-cols-2` on tablet, `grid-cols-1` on mobile) separated by `1rem` gutters.
- **Split Audit Layouts:** Carrier profile detail screens use a 3-column asymmetric layout: 2 columns for the compliance dossier, insurance verification checks, and inspection history; 1 column for the chameleon risk engine scorecard and dispatch action triggers.
- **Table Density:** Row height is strictly constrained: 36px for compact data rows, 44px for primary carrier rows with secondary metadata subtext.

## Elevation & Depth

Visual hierarchy is maintained through layered surface luminance, precise 1px specular highlight insets, and dark ambient occlusion rather than diffuse drop shadows.

### Elevation Tiers
1. **Tier 0 (Deep Ground):** Canvas `#05080f`. Flat, absorbent, non-reflective.
2. **Tier 1 (Panels & Master Cards):** Surface `#0a1020` paired with hairline border `#1b2740`. Enhanced with a physical 1px top specular highlight:
   `box-shadow: inset 0 1px 0 0 rgba(255, 255, 255, 0.03), 0 12px 32px -16px rgba(0, 0, 0, 0.8)`
   This creates a machined, beveled metallic border profile common in aerospace and intelligence terminals.
3. **Tier 2 (Elevated Headers & Modals):** Surface `#0e1628` paired with interactive border `#25334f` and a deeper shadow stack:
   `box-shadow: inset 0 1px 0 0 rgba(255, 255, 255, 0.05), 0 20px 48px -12px rgba(0, 0, 0, 0.9)`
4. **Tier 3 (Floating Drawers & Overlays):** Full-bleed slide-over inspection drawers and context menus sit on surface `#0a1020` with a full-viewport backdrop dim:
   `background: rgba(5, 8, 15, 0.7); backdrop-filter: blur(4px);`

### Focus & Signal Radiance
Elevated focus states do not rely on generic browser outlines. Focused controls emit an electric signal azure outer ring:
`box-shadow: 0 0 0 2px #05080f, 0 0 0 4px #6ba4ff`

## Shapes

The design uses tight, controlled corner radii that balance modern UI aesthetics with industrial density. 

### Geometry Rules
- **Micro Elements (`rounded-sm` / 4px):** Checkbox boxes, radio pips, equipment tags, and inline table status dots.
- **Standard Controls (`rounded-md` / 8px):** Form inputs, default buttons, select menus, search fields, and metadata chips.
- **Panels & Dossiers (`rounded-lg` / 14px):** Scorecards, verification summary cards, inspection panels, and evidence dialog containers.
- **Status Pills (`rounded-full` / 9999px):** Vetting decision indicators (`PASS`, `FAIL`, `NEEDS_REVIEW`, `UNKNOWN`), load status tags, and counter badges.
